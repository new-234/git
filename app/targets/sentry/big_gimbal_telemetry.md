# 大云台 PID 调试遥测

## 串口与格式

- 串口：`UART7`
- 引脚：`PE7 = RX`，`PE8 = TX`
- 波特率：`115200`
- 格式：`8N1`
- 上位机：VOFA+ `JustFloat`
- 发送频率：50 Hz

每一帧由 25 个 little-endian `float32` 和固定帧尾
`00 00 80 7F` 组成，共 104 字节。

## 通道映射

| 通道 | 内容 | 单位/含义 |
|---:|---|---|
| 0 | 大云台控制模式 | 0=NoForce, 1=Init, 2=RC, 3=Navi, 4=Keep |
| 1 | 遥控 yaw 使能 | 0=关闭, 1=开启 |
| 2 | yaw 角度环 Kp | 当前生效值 |
| 3 | yaw 角度环 Ki | 当前生效值 |
| 4 | yaw 角度环 Kd | 当前生效值 |
| 5 | yaw 速度环 Kp | 当前生效值 |
| 6 | yaw 速度环 Ki | 当前生效值 |
| 7 | yaw 速度环 Kd | 当前生效值 |
| 8 | 目标 yaw 角度 | deg |
| 9 | 当前 yaw 角度 | deg，AHRS 解算值 |
| 10 | 角度环误差 | deg，目标值减当前值 |
| 11 | 角度环输出，即目标角速度 | deg/s |
| 12 | 当前角速度 | deg/s，BMI088 陀螺仪 |
| 13 | 速度环误差 | deg/s，目标角速度减当前角速度 |
| 14 | 角度环 P 输出 | deg/s |
| 15 | 角度环 I 输出 | deg/s |
| 16 | 角度环 D 输出 | deg/s |
| 17 | 速度环 P 输出 | 原始控制量 |
| 18 | 速度环 I 输出 | 原始控制量 |
| 19 | 速度环 D 输出 | 原始控制量 |
| 20 | 速度环总输出 | 原始控制量，送给达妙电机前 |
| 21 | 实际前馈力矩指令 | N·m |
| 22 | 下 yaw 电机实测角度 | deg，相对机械零点 |
| 23 | 下 yaw 电机实测角速度 | deg/s |
| 24 | 遥控器左摇杆 X 输入 | -1.0 到 1.0 |

## 调参时重点观察

- 角度环：通道 `8/9/10`，用于观察目标、当前和误差。
- 速度环：通道 `11/12/13`，用于判断速度跟踪和速度环阻尼。
- 控制量：通道 `17/20/21`，用于判断是否饱和、是否有高频抖动。
- 机械反馈：通道 `22/23`，用于区分电机反馈和 IMU 解算异常。

遥控模式下应看到：

- 通道 `0 = 2`。
- 通道 `1 = 1` 时左摇杆才能改变目标 yaw。
- 左摇杆和通道 `24` 方向一致。
- 通道 `11` 能合理跟踪，通道 `13` 不应长期很大。
- 通道 `20` 不应持续贴近 `+50000` 或 `-50000`，否则速度环已经饱和。
